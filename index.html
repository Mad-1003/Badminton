1. 기본 설정

저장한 기본 설정은 이 브라우저에서 자동 불러오고, “현재 파일 저장”으로 저장하면 배포용 파일에도 포함됩니다.

2. 참가자 입력 / 저장 명단

참가자 일괄 등록

입력 형식: 이름 또는 이름,성별,실력,중복참여(O/X). 엑셀에서 복사한 탭 구분 형식도 지원합니다.

이전 버전(v2~v4)의 참가자 저장 데이터와 저장 명단을 자동으로 읽습니다. 이름을 추가하거나 성별/실력/중복 참여 여부를 수정하면 저장됩니다. 이전 버전 명단도 자동으로 불러옵니다.
