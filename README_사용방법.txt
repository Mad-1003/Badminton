# KRIBB 배드민턴 대회 팀 자동 생성기 PWA

이 폴더를 웹에 올리면 핸드폰에서 앱처럼 설치할 수 있습니다.

## 가장 쉬운 사용법
1. 이 ZIP 파일을 압축 해제합니다.
2. `index.html`, `manifest.json`, `service-worker.js`, `icons` 폴더를 GitHub Pages, Netlify, Cloudflare Pages 등에 업로드합니다.
3. 휴대폰에서 생성된 링크로 접속합니다.
4. Android Chrome/삼성 인터넷: 메뉴 → 홈 화면에 추가 또는 앱 설치
5. iPhone Safari: 공유 버튼 → 홈 화면에 추가

## 중요
- PWA 설치는 보통 HTTPS 웹주소에서 정상 작동합니다. 단순히 HTML 파일을 파일 앱에서 여는 방식은 앱 설치가 제한될 수 있습니다.
- 참가자 명단 저장은 사용하는 브라우저/기기별로 저장됩니다.
